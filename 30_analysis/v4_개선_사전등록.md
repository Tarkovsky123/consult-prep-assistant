# 시제품 v4 개선과 새 시험(E2c) 사전등록 (2026-11-06, 시험 실행 전 고정)

사용자 지시(11/6): "모델 개선할 시간 아직 남아있잖아. 계속해서 모델 개선 진행해." 독립 심사(judge-3, 72점)와 레드팀(v4, 81.5점)의 공통 약점은 ① 유형이 있는 사례가 6건뿐인 작은 표본 ② 상세 구조화가 전체의 약 9%(대구·경북)뿐 ③ 금액 소득·구간 상한을 계산하지 못함이다.

## 1. 지켜야 할 것

- 지금까지의 세트(E2 개발 30, E2b 20, 합성 11, E1 96건·추가 100)는 모두 정답을 본 세트다. 여기서 잰 v4 점수는 **개발 점수**로만 적고, 제안서의 성능 주장에는 쓰지 않는다.
- 제안서에 넣을 v4 성능은 **E2c**(아래)로만 잰다. 순서: E2c 표본 고정 → 사용자 판정(모델 출력 안 봄) → 정답표 고정(sha256) → v4 코드 고정(sha256) → **E2c에 한 번만 실행** → 결과를 좋든 나쁘든 그대로 기록.
- E2c 정답표를 고정하기 전에는 E2c 사례에 시제품을 돌리지 않고, 사례 원문을 보며 규칙을 고치지 않는다.
- 숫자는 실제로 돌린 것만 쓴다. 기준선('항상 일반', '항상 해당 없음', 규칙)도 같이 낸다.
