## 디자인(11/5, contest 스킬 design.md 기준)

- **KRDS를 따른다.** 공공 서비스 화면을 보여 주는 공공기관 대회라서다(design.md §6). 색·글자 크기·모서리는 KRDS 공식 토큰 값을 쓴다(github.com/KRDS-uiux/krds-uiux `resources/css/token/krds_tokens.css`, 2026-01-12 갱신).
  - 바탕 gray-5, 카드 gray-0, 글자 gray-90/70, 테두리 gray-20/30, 주색 primary-50/60
  - 판정 색: 신속 = success, 확인 필요 = warning, 협의제외 = information, 일반 = gray
  - 근거 구절 표시 = primary-10
  - 어두운 화면은 KRDS '선명한 화면 모드' 역할 토큰을 쓴다.
- 글자 크기는 KRDS 단계 중 다섯 가지만 쓴다(13·15·17·19·24px). 탭은 KRDS 밑줄형, 배지는 테두리형이다.
- **글꼴**: KRDS 지정 서체 **Pretendard GOV** 1.3.9(OFL)의 Regular·Bold를 쓴다.
  - 11/5 사용자 승인으로 공식 릴리스(github.com/orioncactus/pretendard, `PretendardGOV-1.3.9.zip` 112MB)에서 받았고, 공용 키트 `_공통/fonts/Pretendard GOV/`에 넣었다.
  - 페이지에 쓰인 글자 536자만 잘라 WOFF로 넣었다(굵기마다 약 65KB).
  - 브라우저에서 두 굵기 모두 실제로 불러와지는 것(loaded)을 확인했다. 대체 글꼴로 넘어가지 않았다.
- AI 티로 꼽힌 것을 뺐다: 고정폭 작은 라벨, 자간 넓힌 작은 제목, 부리·민부리 혼용, 글상자 옆 색 막대.
- 대비: 글자 조합은 모두 4.5:1 이상이다(가장 낮은 것은 밝은 화면 협의제외 띠 5.04).

## 제안서용 캡처(`캡처/`, 720px 보기를 2배 해상도로 찍음)

- 11/5 저녁 design.md 기준(그림 안 글자는 쪽 기준 9pt 이상)에 맞춰 960px에서 720px로 줄였다. 가장 작은 글자 15px가 칸 폭 16cm에서 9.4pt, 본문 17px가 10.7pt다.
- 16cm보다 좁게 넣으면 9pt 아래로 내려가니 줄여 넣지 않는다.
- 11/5 밤 독립 채점(judge-1 #20) 반영: 캡처 보기에서 내부 사례 번호를 뺐고, 배지를 풀어 썼다(대상: 확인 필요 · 상한: 범위 안 · 중복·보충 조건: 위반 근거 없음 · 협의제외: 해당 안 됨). 원문 발췌는 ○·□ 앞에서 줄을 바꾸고 근거 구절이 든 줄만 남긴다(범례에 "근거가 든 줄만 옮겼습니다"). 배지 문구는 일반 보기에도 같이 바뀐다. 시연 화면 v6으로 다시 올림.
- 11/5 밤 한글 붙이기: 판정근거 보기에서 사업명 머리를 빼고(캡션에 있음) 캡처 보기 여백을 줄였다(1440×1004). 제안서에는 폭 15.3cm로 넣어 가장 작은 글자가 9.0pt다. 15.2cm보다 좁히지 않는다. 시연 화면 HTML은 다시 올리지 않았다(캡처 보기만 바뀜).
- 그림 한 장에 메시지 하나만 둔다. 판정근거 그림에는 판정 띠, 원문 근거 구절 발췌 2개, 대상·상한 대조만 남겼다. 문구는 모두 시제품 출력 그대로다.

## 정직하게 보이기 위한 처리(`prep.py`)

- **협의 이력**: 이 사례 자신의 2025년 협의 기록을 빼고, 뺐다고 표시한다.
- **같은 지자체 비교 대상**
  - 변경 사례: 기존 사업이 실제 비교 대상이라 '변경 대상 기존 사업'으로 표시한다.
  - 신설 사례(474): 협의 뒤 복지로에 등록된 사업 자체는 당시 없던 사업이라 빼고, 뺐다고 표시한다.
- **원문의 특수 글머리**(사용자 정의 영역 문자 U+F06D)는 글꼴에 없어 네모로 깨진다. 그래서 □로 바꿨다(원문·근거 구절 모두 같게).
- LLM이 근거로 든 구절(유형·대상·중복·협의제외)은 원문에서 찾아 형광으로 표시한다. 못 찾으면 표시하지 않는다.

## 확인한 것

- 데스크톱 폭: 화면 없는 Chrome으로 1280px 이미지를 찍어 봤다.
- 휴대폰 폭: 브라우저 창에서 375px로 쟀다. 문서 폭이 375px로 가로 넘침이 없고, 체크리스트·차이표는 표 안에서만 스크롤된다. Pretendard도 불러와졌다.
  - 화면 없는 Chrome은 창 폭에 최솟값이 있어 390px 이미지가 잘려 나온다. 그래서 휴대폰 폭은 브라우저 창으로만 확인한다.
- 게시본은 브라우저 창이 claude.ai에 로그인돼 있지 않아 같은 HTML을 로컬 서버로 띄워 확인했다(`.claude/launch.json`의 e3-preview).
