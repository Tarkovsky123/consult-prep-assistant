## 2. 읽는 법

1. **AI가 확실히 더한 것은 '79개 유형 중 맞는 것 찾기'다.**
   - 새 사례에서 50%(10/20)가 75%(15/20)로, 합성 경계사례에서 64%가 91%로 올랐다.
   - 키워드 규칙은 낱말이 겹치면 목적이 달라도 붙이고(748 한방 난임 → 1번 시술비), 낱말이 안 겹치면 놓쳤다. v2는 급여 항목으로 골랐다(544 중장년 자격증 → 24번, 206 청년 월세 → 39번).
2. **최종 판정은 거의 오르지 않았다.**
   - 시험 A는 일반협의가 15/20이라 '항상 일반'만으로도 75%가 나온다. M2의 85%(17/20)는 그보다 2건 많을 뿐이다.
   - 이 표본에서 판정을 가르는 신속 4건은 세 방법 모두 맞혔다. M2와 M1은 잘못 신속을 권한 사례가 없다.
3. **경계 사례(시험 B)는 v1 규칙 단계가 병목이다.** M2가 유형을 맞힌 뒤에도 틀린 6건 중 5건이 금액·대상 규칙 단계에서 났다. 이 단계는 세 방법이 같다.

| 사례 | 정답 | M2 | 원인(규칙 단계) |
|---|---|---|---|
| S1 출산용품 50만 원 | 밖 → 일반 | 확인불가 | 구간별 상한(첫째 30/둘째 40/셋째 50만 원)을 계산하지 못하고 보류 |
| S8 산모·신생아 본인부담 100% | 밖 → 일반 | 확인불가 | 비율 상한(90%)끼리 비교하지 못하고 보류 |
| S9 둘째 양육수당 + 도 다자녀수당 | 안 → 신속 | 확인불가 | 광역 합산·구간별 상한을 계산하지 못하고 보류 |
| S3 자격증 응시료 + 운전면허 | 일반(중복 위반) | **신속** | 중복·보충 조건을 판단하지 않음(사전등록에 적은 한계) |
| S5 전입축하금(인구소멸지역 아님) | 밖 → 일반 | **신속** | 유형 대상의 지역 조건을 대상 대조에 넣지 않음 |
| S11 '청년 주거 지원'(금액 없음) | 39번 · 확인불가 | 해당없음 · 일반 | v2가 유형을 못 고름(정보가 너무 적은 사례) |

   - 3건(S1·S8·S9)은 사람에게 넘기는 보류여서 안전한 쪽으로 틀렸다. 그래도 지표에서는 '불필요한 보류'로 센다.
   - 2건(S3·S5)은 신속을 잘못 권했다. 이것이 가장 먼저 고칠 위험이다.
4. **협의제외는 v2가 새로 잡은 것과 새로 틀린 것이 같이 있다.**
   - 개발 세트에서 키워드 오판 434·485와 누락 481은 바로잡았다.
   - 대신 484(발달장애인 안심보험 → 배상책임보험 범주)와 시험 A 1122(청년창업 특례보증 → 중소기업지원사업)를 제외로 판단했고, 정답표는 둘 다 협의대상이다.
   - 두 건 모두 지침 문구를 근거로 들었지만 정답표는 고정이라 고치지 않는다. 판단이 갈리는 사례로 공개한다.

## 3. 제안서에 쓸 수 있는 문장과 쓸 수 없는 문장

- 쓸 수 있다
  - "대구·경북 밖 새 협의 사례 20건에서, 79개 신속협의 유형 중 맞는 유형을 찾는 정확도는 키워드 규칙 10/20, LLM 유형 선택 15/20이었다(정답표는 도구 실행 전 고정)."
  - "최종 유형 판정은 17/20이었다. 이 표본은 일반협의가 15건이라 판정 정확도만으로는 차이가 작다. 신속 4건은 모두 맞혔고, 잘못 신속을 권한 사례는 없었다."
  - "제안자가 만든 경계 사례 11건에서는 5/11이었다. 구간별·비율 상한, 지역·중복 조건을 아직 계산하지 못해서다. 3건은 담당자 확인(보류)으로 넘겼고 2건은 신속을 잘못 제안했다." 이 실패와 개선 계획을 함께 쓴다.
- 쓸 수 없다
  - '항상 일반' 기준선을 빼고 "판정 정확도 85%"만 쓰는 것
  - 개발 세트 점수(23/29)를 정확도로 쓰는 것
  - 표본 31건으로 전국 정확도를 일반화하는 것
