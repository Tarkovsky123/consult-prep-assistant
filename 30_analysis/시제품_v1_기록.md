## 시험 (합성 사례 2건만, E1·E2 라벨 대상 아님)

라벨 대상 96개 사업명에 '가족사진'·'문화포인트'가 없는 것을 확인한 뒤 시험했다.

| 사례 | 기대 | 결과 |
|---|---|---|
| 영덕군 다자녀(셋째 이상) 가족사진 1회 25만원, 1년 거주, 소득 무관, 타 지자체 수혜 제외 | 연번 10(가구당 최대 30만원) → 범위 안 | **일치.** 추출: 금액 250,000·1회·거주 한정 영덕군·예외 조건 1개, 근거 구절 불일치 0 |
| 수성구 청년 문화포인트 연 30만원, 6개월 거주, 소득 기준 없음, 문화누리카드 수혜 제외 | 연번 18(연 20만원, 중위 150% 이하) → 범위 밖(금액·소득 두 이유) | **일치.** 두 근거가 모두 표시됨 |

- 출력 예시: `30_analysis/시제품_예시/합성_*.md`
- LLM: Codex CLI 기본 모델, 추론 medium, 사례당 1회 호출

## 아직 안 한 것

- **실제 사례 평가**: E2 정답표(라벨)를 고정한 뒤 30건에 돌려 정확도·불필요한 보류를 잰다. 라벨 전에는 E2·E1 사례에 돌리지 않는다.
- **구간별 상한**: 출생순위·소득구간별 상한은 여전히 '확인불가(구간별 상한)'다. 구간을 지정하는 입력은 E2 결과를 보고 정한다.
- **중앙부처 조건 대조**: '한국사회보장정보원_중앙부처복지서비스' API 상세(지원대상·선정기준 원문)가 필요하다. 사용자 활용신청이 필요한지 확인한다.
- **다른 시도 구조화**: 비용은 Codex 호출 기준 건당 약 4초다. 전국 4,828건이면 병렬 4개로 약 1.5시간이다. API 상세는 하루 1,000건 한도라 5일이 걸린다.
- **E1 내용 기반 검색 방식**: 구조화 조건으로 걸러 내는 검색을 별도 방식으로 만들 수 있다. 평가는 E1 라벨 뒤에 한다.
