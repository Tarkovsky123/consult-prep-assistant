> - 협의 대상·제외: Ⅱ.2~4, PDF 20~33쪽(인쇄 10~23쪽)
> - 신속협의: Ⅱ.5, PDF 34~41쪽(인쇄 24~31쪽)

## 0. 공통 원칙

1. **원문 = 사업안이다.** [라벨 규칙] E2의 원문 세 칸(지원대상·선정기준·지원내용)이 협의를 요청하는 사업안이라고 보고 판정한다. 협의 당시 실제 요청서는 볼 수 없으니, 도구도 같은 원문만 받는다.
2. **원문에 없는 것은 추측하지 않는다.** 근거가 없으면 `확인불가`다.
3. **근거가 있는데 확인불가를 고르지 않는다.** 그러면 '불필요한 보류'의 정답이 흐려진다.
4. **판정을 바꾸지 않는다.** 단 뒤에는 고치지 않고, 고쳐야 하면 메모에 사유를 남긴다.
5. **헷갈리면 메모한다.** 한 줄이면 충분하다. 예: "광역 사업 중복 여부를 원문으로 알 수 없음"

## 1. E2: 칸별 판정 규칙

E2 시트(`E2_요건대조_라벨시트.xlsx`)의 노란 칸 다섯 개를 **아래 순서대로** 채운다.

### ① 동일 사업인가 (예 / 아니오 / 불확실)

'협의 사업명'과 '복지로 사업명·원문'이 같은 사업인지 본다. 이름 유사도로 짝지은 것이라 다른 사업이 섞여 있다.

| 고를 값 | 기준 |
|---|---|
| **예** | 기관이 같고(협의요청기관과 복지로 시군구), 목적과 대상이 같다. 이름이 조금 달라도(예: '○○ 지원사업' vs '○○ 지원') 예 |
| **아니오** | 대상이나 목적이 다른 별개 사업이다. 예: 협의 '청년 월세 지원' vs 복지로 '청년 전세보증금 이자 지원' |
| **불확실** | 원문이 짧아서 같은지 알 수 없다 |

- **아니오**이면 나머지 네 칸은 비운다. [지침 외, README 규칙]
- **불확실**이면 원문 기준으로 나머지를 채우고, 메모에 "동일 여부 불확실"이라고 쓴다. [라벨 규칙]

### ② 해당 신속협의 유형 연번 (1~79 / 해당없음)

'신속유형_참고' 시트의 79개 유형 중, **사업명과 대상이 가장 가까운 것 하나**를 고른다.

- **고르는 기준** [라벨 규칙]: ⑴ 무엇을 지원하는가(급여 항목) ⑵ 누구에게(대상)
  - 예: 출산가정에 출산용품 → 7번 '출산·육아용품'. 출생아 사진 → 9번. 다자녀 가족사진 → 10번
- **후보가 둘 이상**이면 급여 항목이 더 정확히 맞는 쪽을 고르고, 다른 후보는 메모에 적는다.
- **해당없음**: 급여 항목이 같은 유형이 없을 때. 단어만 겹치는 유형은 고르지 않는다.
  - 예: '청년 정장 구입비' → 면접 서비스(20번)와 비슷해 보이지만 급여 항목이 다르다. 그러면 해당없음과 메모 "20번 면접 서비스와 유사"
- 해당없음이면 ③④는 비우고 ⑤로 간다.
- **광역(본청) 사업이어도 맞는 유형이 있으면 연번을 적는다.** ③④도 채운다. 신속이 안 되는 이유는 ⑤에서 처리한다. [라벨 규칙]
- **6번(출산축하금·양육수당)은 '2자녀 이상 다자녀' 사업에만 붙인다.** 유형 이름에 '(2자녀 이상 다자녀)'가 있어서다. 첫째부터 주거나 다자녀라는 말이 원문에 없는 출산축하금·양육수당은 **해당없음**이다(E2 392, E2b 304·350·195·985). 초다자녀 가정 지원처럼 출산을 기준으로 하지 않는 다자녀 사업도 6번이 아니다(E2b 1096). [라벨 규칙, 11/3 사용자 판정에서 확인]

### ③ 대상이 유형 범위 안인가 (안 / 밖 / 확인불가)

사업안의 대상이 유형의 '대상' 칸보다 **좁거나 같으면 안**, **넓으면 밖**이다. 신속협의 기준은 "최근 협의완료 사례(신속협의 유형 사업 목록)와 비교 시 지원대상, 지원금액 등이 범위 내에 포함될 경우"다. [지침 Ⅱ.5]

| 상황 | 판정 | 예(지어낸 사례) |
|---|---|---|
| 유형 대상이 넓다('전체', '일반', '출산가정', '청년')고 사업안이 그 안 | **안** | 유형 '청년' ⊇ 사업안 '만 19~34세 미취업 청년' |
| 유형에 소득 기준이 있고, 사업안 소득 기준이 같거나 더 낮다 | **안** | 유형 '중위소득 180% 이하 청년' vs 사업안 '중위소득 150% 이하 청년' |
| 유형에 소득 기준이 있는데, 사업안에 **소득 제한이 없다고 적혀 있다** | **밖** | 유형 '중위소득 150% 이하 청년' vs 사업안 '소득 기준 없음' |
| 유형에 소득 기준이 있는데, 사업안이 **소득을 아예 언급하지 않는다** | **확인불가** | 원문에 소득 관련 말이 없음 |
| 사업안 소득 기준이 '저소득층'처럼 %가 아니라 유형 %와 비교할 수 없다 | **확인불가** | 유형 '중위소득 100% 이하' vs 사업안 '저소득 가구' |
| 사업안 소득 기준이 유형보다 높다 | **밖** | 유형 중위 100% vs 사업안 중위 120% |
| 유형이 특정 자격(수급자·차상위 등)인데 사업안은 더 넓은 집단이다 | **밖** | 유형 '장애인(기초생활수급자, 차상위계층)' vs 사업안 '등록장애인 전체' |
| 연령: 유형 연령 범위 안 | **안** | 유형 '만 90세 이상' vs 사업안 '만 95세 이상' |
| 연령: 유형보다 넓다 | **밖** | 유형 '만 90세 이상' vs 사업안 '만 85세 이상' |

참고
- **거주 요건**('○○군 6개월 이상 거주')은 대상 범위 판단에 쓰지 않는다. 유형 목록에 거주 요건이 없기 때문이다. [라벨 규칙]
- **유형 쪽의 지역 조건은 대상으로 본다.** [라벨 규칙, 11/3 합성 S5로 확정]
  - 예: 33번 전입축하금의 '(인구소멸지역·농산어촌지역)'처럼 유형이 사업하는 지역을 정해 두었으면, 그 지역이 아닌 지자체의 사업은 대상 **밖**이다.
  - 위의 '거주 요건'(주민이 얼마나 살았나)과는 다른 것이다.
- **기준중위소득 표기**: '중위소득 150% 이하' = '기준 중위소득 150% 이내'로 같은 뜻으로 본다.

### ④ 지원수준이 상한 안인가 (안 / 밖 / 확인불가)

사업안 금액이 유형의 '지원수준(최대 상한)' 이하이면 안이다. 유형 표의 금액은 **최대 상한**이다. [지침, 목록 머리말 "제시금액은 최대 상한임"]

**기간 맞추기** [라벨 규칙, 도구와 같음]

| 사업안 \ 유형 | 비교 방법 |
|---|---|
| 월 금액 vs 연 상한 | 월 × 12로 연 금액을 만들어 비교 |
| 연 금액 vs 월 상한 | 연 ÷ 12로 비교. 분할 지급 조건이 있으면 메모 |
| 1회 금액 vs 연 상한 | 1회 = 그해 1회로 보고 그대로 비교 |
| 1회(생애 1회) vs 1회 상한 | 그대로 비교 |
| 총액(예: 2년 총 480만원) vs 총액 상한 | 총액끼리 비교. 월 상한도 따로 있으면 둘 다 만족해야 안 |

**상황별 판정**

| 상황 | 판정 |
|---|---|
| 금액이 원문에 없다('예산 범위 내', '실비'만 있고 한도 없음) | **확인불가** |
| '실비 지원, 최대 ○원' | 최대 금액으로 비교 |
| 유형 상한이 **비율**(본인부담금 90% 등)이고 사업안도 비율 | 비율끼리 비교 |
| 유형 상한이 비율인데 사업안은 금액만 있다 | **확인불가** |
| 유형 상한이 **구간별**(출생순위·연령·소득 구간별) | 사업안의 **모든 구간**이 해당 구간 상한 이하이면 안, 한 구간이라도 넘으면 밖, 구간을 알 수 없으면 확인불가 |
| 6번 출산축하금·양육수당 | 상한이 **광역+기초 지원금 총합**이고, 그 지자체의 유사 현금사업까지 합한 금액이다. **원문에 광역 금액이 적혀 있으면 합산해 판단**하고, 메모에 "광역 합산 확인 필요"라고 쓴다(11/3 합성 S9로 확정). 원문에 광역 금액이 없으면 → 사업안 혼자서 이미 넘으면 **밖**, 아니면 **확인불가** + 메모 "광역 합산 미상" |
| '중앙 단가 준용'(8번 기저귀·조제분유 등) | 사업안이 그 단가 이하이면 안 |
| 여러 급여 항목(사진 촬영비 + 앨범비) | 항목마다 그 항목의 상한과 비교. 하나라도 넘으면 밖 |
| 자부담 설정 필수(19·24번 등)인데 원문에 자부담이 없다 | 금액만으로 ④를 판정하고, 메모에 "자부담 조건 미확인" |

### ⑤ 유형 판정 (협의제외 / 신속 / 일반 / 확인불가)

아래 **순서도대로** 정한다.

```
[1] 협의제외 대상인가? (2장 목록)
    ├─ 예, 그리고 '적용불가'(2.1)에 걸리지 않음 ──────────────▶ 협의제외
    ├─ 애매함(원문만으로 제외 사유를 확정할 수 없음) ───────────▶ 확인불가 + 메모
    └─ 아니오
        ▼
[2] 협의요청기관이 기초지자체(시·군·구, 세종·제주 포함)인가?
    ├─ 아니오(광역 본청·교육청 등) ───────────────────────────▶ 일반
    └─ 예
        ▼
[3] ② 연번이 '해당없음'인가? ───────── 예 ──────────────────▶ 일반
        ▼ 아니오
[4] ③·④ 중 하나라도 '밖'인가? ─────── 예 ──────────────────▶ 일반
        ▼ 아니오
[5] ③·④ 중 하나라도 '확인불가'인가? ── 예 ──────────────────▶ 확인불가
        ▼ 아니오 (둘 다 '안')
[6] 유형의 '중복·보충 조건'을 원문이 어긴다고 드러나는가?
    ├─ 예(예: 중앙 사업과 중복 제거 필수인데 원문에 중복 수혜 가능) ▶ 일반 + 메모
    └─ 아니오 / 원문에 언급 없음 ────────────────────────────▶ 신속
```

**판정의 근거** [지침 Ⅱ.5]
- 신속협의 대상기관은 기초지방자치단체다(기초 없는 세종·제주 포함). 그래서 광역 사업은 신속이 될 수 없다.
- 신속협의 요건을 채우지 못하면 일반·쟁점 사업으로 재분류될 수 있다(신청 접수 후 1주일 이내).
- [6]에서 '언급 없음'을 신속으로 두는 이유 [라벨 규칙]: 중복 여부는 원문이 아니라 담당자가 확인할 일이다. 원문에 위반이 드러날 때만 일반으로 내린다.

**변경 건 처리** [라벨 규칙]
- 원문에는 '무엇이 바뀌었는지'가 없다. 그래서 행정적 변경협의 제외(2.2의 변경 전용 항목)는 원문으로 판단하지 않는다.
- 사업 성격 제외(2.3)와 신속 요건만 본다.
- 변경 내용이 판정을 가를 것 같으면 메모에 "변경 내용 미상"이라고 쓴다.

## 2. 협의제외 목록 요약 (지침 Ⅱ.3, PDF 21~33쪽)

### 2.1 먼저 볼 것: 제외가 안 되는 경우(적용불가)

아래에 해당하면 2.2~2.4에 들어도 **협의대상**이다.

- **사회보험 재정에 직접 영향을 주는 사업**. 예: 건강보험 본인부담금 지원 [PDF 21]
- **중앙·광역(교육청 포함)·같은 기초 타 부서 사업과 지원대상·지원목적이 중복**되는 경우 [PDF 23]
- **고액 현금 지원**: 중앙지침·수납한도·실비 같은 지원수준 기준이 없는 사업 중, 통상적·일회성 수준을 넘는 고액 현금 [PDF 23]
- 참고: 기초연금 유사 급여 주의 [PDF 24]
  - 다음 여섯 요건을 모두 갖추면 국고보조금 감액 대상이다: ① 만 65세 이상 ② 현금성 ③ 소득보전·생활지원 목적 ④ 소득·재산 구분 없음 ⑤ 노인 당사자 수급 ⑥ 정기 지급
  - 제외 여부와는 별개지만, 해당하면 메모한다.

### 2.4 지자체 사업만 해당하는 제외 [PDF 30~33]

- **중앙지침에 기속된 의무·권고사업**: 중앙부처가 일괄 협의하거나 지침으로 갈음한다.

- **(변경) 거주요건만 변경**
- **보훈·피해보상**: 국가유공자·참전유공자 명절위문금, 국립묘지 이장비, 의사상자, 과거사 피해자(선감학원·형제복지원 등)
- **지역 자율형 사업**: 지역사회서비스투자사업, 지역사회통합건강증진사업, 행안부 지역주도형 청년일자리 등
- **의료·요양 통합돌봄 지자체 특화사업**

  - 대상을 통합돌봄 대상자로 한정하거나 우선 선정하는 경우에만 제외된다.

### 2.5 협의제외 판정에서 자주 헷갈리는 것 [라벨 규칙]

- **'현물 vs 현금'이 갈림길인 범주가 많다.** 예: 전입 축하 현물은 제외인데 전입축하금(현금)은 협의대상이다(신속 33번에 있음). 교통 '요금 지원'은 제외인데 '직접 교통비'는 협의대상이다.
- **단일 물품 vs 꾸러미**: 아기 띠도장 하나는 제외, 출산용품 꾸러미는 협의대상(신속 7번)이다.
- **협의제외 범주와 신속 유형이 동시에 떠오를 때**: 신속 유형 목록에 같은 사업이 있으면 협의대상으로 보는 편이 맞다. 예: 33번 전입 지원금. 메모를 남긴다.
- 원문이 짧아 범주를 확정할 수 없으면 `확인불가` + 메모 "제외 사유 미확정"

## 3. E1: 유사쌍 판정 규칙

E1 시트(`E1_유사쌍_판정시트.xlsx`)는 같은 '사례' 번호가 협의 사업 하나와 그 후보들이다. 후보마다 **동일 / 유사 / 무관**을 고른다.

**판정할 때 던질 질문**: "이 협의 사업의 요청서 4절 '기존 제도와의 관계'에 비교 대상으로 **적어야 하는** 사업인가?"
- 적어야 하면 동일 또는 유사다.
- 적을 필요가 없으면 무관이다.
- 이 라벨이 '필수 비교사업' 정답이 된다.

### 3.1 세 가지를 본다

| 요소 | 뜻 | 예(지어낸 사례) |
|---|---|---|
| **목적** | 어떤 필요·위험에 대응하나 | 출산 축하·양육비 경감 / 청년 주거비 / 취업 준비 비용 / 노인 의료비 |
| **대상 집단** | 누구에게 | 출산가정 / 청년 / 다자녀 가구 / 장애인 / 노인 |
| **급여 형태** | 무엇으로 주나 | 현금(지역화폐 포함) / 현물 / 바우처·이용권 / 서비스 / 감면 / 융자·이자 |

### 3.2 판정

| 판정 | 기준 | 예 |
|---|---|---|
| **동일** | 목적·대상 집단·급여 형태가 **모두 같다**. 지역, 금액, 세부 연령·소득 기준이 달라도 동일이다 | 협의 'A군 둘째 출산축하금 100만원' vs 후보 'B시 출산장려금(둘째 이상) 50만원' |
| **유사** | 목적은 같고, 대상 집단이나 급여 형태 중 **하나 이상이 다르다** | 'A군 출산축하금(현금)' vs 'B시 출산용품 꾸러미(현물)'. 또는 '청년 월세 지원' vs '신혼부부 월세 지원' |
| **무관** | 목적이 다르다. 낱말만 겹친다 | '청년 월세 지원' vs '청년 면접비 지원'. 또는 '노인 목욕비' vs '노인 일자리' |

### 3.3 경계 사례 [라벨 규칙]

- **목적이 일부만 겹치면**(예: '청년 주거·생활 종합 지원' vs '청년 월세') **유사**로 본다.
- **협의 사업 그 자체가 복지로에 등록된 경우**(같은 기관·같은 사업): **동일**로 하고, 메모에 "같은 사업"이라고 쓴다.
- **같은 지자체의 다른 부서·다른 연도 사업**도 위 기준대로 판정한다. 중복 검토 대상이라 오히려 중요하다.
- **광역(도·시 본청) 사업과 기초 사업**: 목적·대상·형태가 같으면 동일이다. 광역 중복 확인이 서식에 있다.
- **금액 단위가 크게 달라도**(예: 10만원 vs 500만원) 형태가 같으면 동일이다. 금액 차이는 메모만 한다.
- **요약이 짧아 판단할 수 없으면** 칸을 비우고 메모에 "판단 불가"라고 쓴다. 평가에서 뺀다.
- **한 사례의 후보가 모두 무관이면** 그 사례 아무 행의 메모에 "후보 없음"이라고 쓴다. 검색이 놓친 사례로 쓴다.
- **이름 유사도·검색 방식은 보지 않는다.** 시트에서 뺐다. 원본 CSV도 열지 않는다.
