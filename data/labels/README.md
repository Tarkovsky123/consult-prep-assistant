# 사람 라벨 안내

AI 추출 정확도를 재는 정답셋입니다. **라벨을 다 달기 전에는 `data/processed/structured_*.jsonl`(모델 출력)을 열지 마세요.** 모델 답을 보고 라벨을 달면 평가가 무효가 됩니다.

## 시트

| 파일 | 내용 | 상태 |
|---|---|---|
| `private_label_sheet.xlsx` | 민간복지서비스 40건. 소득·지역 조건이 있는 사업과 없는 사업을 절반씩 무작위로 뽑음(시드 20261101) | 라벨 대기 |
| `local_label_sheet.xlsx` | 대구·경북 지자체 복지서비스 60건 | API 수집 뒤 생성 |

## 다는 법

**공통 원칙**
- `원문` 칸만 보고 판단합니다. 원문에 근거가 없으면 비워 두거나 '미상'을 고르세요. 상식으로 추측하지 않습니다.
- 여러 개를 고를 때는 `;`로 구분합니다(예: `아동;청소년`).

**항목별 기준**
- **life (생애주기):** 학년이 나오면 초등=아동, 중·고=청소년, 대학=청년으로 봅니다.
- **household (가구 상황):** 수급자·차상위·저소득층이 대상이면 `저소득`을 넣습니다.
- **income_type (소득 자격)**
  - 기초생활수급자만 대상이면 `기초생활수급`
  - 차상위 이하면 `차상위`
  - 기준중위소득 %로 정하면 `중위소득기준`이고, 숫자를 `income_median_pct`에 적습니다.
  - 그 밖의 소득 기준(예: "저소득층", "건강보험료 기준")은 `기타소득기준`
  - 소득 제한이 없다고 밝히면 `소득무관`
  - 언급이 없으면 `미상`
- **region_type (지역 요건)**
  - 특정 지역 거주자만 대상이면 `거주지한정`이고, 지역명을 `region_name`에 적습니다.
  - 전국 대상이라고 밝히면 `지역무관`
  - 언급이 없으면 `미상`
- **support_form (지원 형태):** 현금, 현물, 바우처·이용권, 서비스, 감면, 융자, 기타 중에서 고릅니다.

40건은 약 40~60분 걸립니다. 애매하면 `메모`에 적어 주세요. 그 사례가 오류 분석의 재료가 됩니다.
